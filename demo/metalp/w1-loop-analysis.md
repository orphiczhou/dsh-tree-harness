## 1. 六阶段逐阶段表：输入 / 输出 / 工件 / 门禁

主链：【原文】「反馈→分析→策划→决策→实施→反馈」+「实施后由总体检视验证结果、残余问题与结构更新，并进入下一轮递归」。注意原文主链写的是五个环节名，但语义上「反馈」环节承担入口与出口双职，加上实施后的总体检视，构成六阶段闭环。

| 阶段 | 输入 | 输出 | 工件（artifact 形态） | 门禁（通过条件） |
|---|---|---|---|---|
| ① 反馈（入口） | 现实返回：事故、需求信号、断言失败、下游消费偏差、环境实测事实（【参考】§1 F1–F5 五层反馈为其分层实例） | 分层归类的反馈账本：每条反馈标注性质（下游需求/传导断点/环境信号/事故沉积）与证据出处 | 反馈盘点表（事件×系统反应×证据 三列，见【参考】§1 F1 表） | 至少一层反馈有可验证出处（【参考】实证 grep 实测、行号级证据）；无证据的「反馈」不得进入分析 |
| ② 分析 | 反馈账本 | 系统坐标：相关系统全景（一横）、稳定对象与功能坐标（一纵）、反馈传导链及断点清单（一链）、方向判断收束（五问） | 坐标文档：四张表（相关系统表 / 稳定对象表 Z / 功能坐标 / 断点清单）+ 五问各一答（【参考】§2 即此形态） | 一横覆盖全部供给与约束方；一纵的稳定对象逐条标注「来源反馈」；一链的断点逐条标注开/闭状态；五问的第 4、5 问（候选方向、本轮逼近方向）非空 |
| ③ 策划 | 系统坐标 + 断点清单 | 六类组织的动作集：每个断点/威胁/缺口被至少一类方法接管，动作有明确落点 | 六类动作表（固本/正源/破链/纠偏/填坑/通渠，各为「动作→落点」映射表，见【参考】§3） | 覆盖性检查：分析产出的每个断点与威胁在策划中可追溯到至少一条动作；每条动作有落点（文件/阶段/Config 键等具体载体），无悬空动作 |
| ④ 决策 | 六类动作集 | 裁决集：候选方向逐条裁决（选/缓/弃）、最紧裕度判定、风险响应分级映射 | APX 裁决表（候选×向心×裁决）+ 相位裕度监控表（对象×偏差信号×恢复动作）+ 分级响应表（【参考】§4） | 向心收敛判据：所有「选」的方向指向稳定对象且无离心项入选（【参考】§4.1 判据原文）；每个稳定对象至少有一个可测偏差信号；每个风险级别有既有机制承接或显式新建 |
| ⑤ 实施 | 裁决集 | 按裁决顺序执行的改变：规约冻结、代码、断言、Config | 任务清单（如【参考】§5.1 S0 清单）+ 代码/规约/断言等实体产物 | 任务清单逐项可勾验；被「缓」的方向记为条件项并写明启用条件（不实施但登记）；护栏/断言随代码同步落盘 |
| ⑥ 总体检视 + 递归 | 实施产物 + 现实运行结果 | 三项检视结论：结果验证（vs 预期）、残余问题清单、结构更新（坐标/稳定对象/断点是否需修订）；下一轮触发判定 | 检视报告 + 递归触发表（触发信号→下一轮动作，见【参考】§5.3） | 结果与裁决预期比对完成；残余问题逐条登记（不静默丢弃）；触发表中至少一条信号被评估（触发或不触发均有记录）；「不求一次求解」——显式留待后续轮的项写明触发条件 |

**递归机制**：【原文】「其核心不是一次性求解，而是在现实反馈中持续逼近动态相对稳定」。第六阶段的触发表即第①阶段（反馈）的下一轮输入，闭环由此成立；触发信号可以是验证失败（回退到②分析，【参考】§5.3 第一行）或新现实反馈（按类型回流至对应层）。

## 3. 递归终止条件与「动态相对稳定」可判定判据草案

**诚实声明**：方法轮原文本身**不设终止条件**——「持续递归」「不是一次性求解」表明该方法论以持续运行为常态，终止只在外部（任务取消、系统退役）发生。因此本节给出的是「一轮可判定收敛」与「弱代理指标」两类判据，不是真正的终止判据。

### 3.1 可操作化判据（强，可直接检验）

| 判据 | 检验方式 | 说明 |
|---|---|---|
| 单轮闭环完整 | 六阶段各自门禁（§1 表）全部通过 | 每一轮的硬验收 |
| 断点收敛 | 一链断点清单中「开」状态断点数不随轮次增加，且老断点逐轮闭合 | 可直接数 |
| 验证通过率 | 断言/差分测试通过率；差分非白名单差异数（【参考】Z5 偏差信号） | 客观可测 |
| 相位裕度不为负 | 各稳定对象的偏差信号均在监控阈值内（【参考】§4.2 监控面逐项可测：并发占用/20、超时判定误差、同族率等） | 量化判据 |
| 触发表静默 | 【参考】§5.3 型递归触发表在观察期内无触发信号 | 静默≠终止，=当前扰动谱下稳定 |

### 3.2 弱代理指标（只能间接逼近）

| 指标 | 为何只能弱代理 |
|---|---|
| 「动态相对稳定」整体达成 | 它相对当前扰动谱定义；扰动谱变化（新下游、新攻击面、新环境）即重置判定，无绝对终态 |
| 向心收敛（无离心方向入选） | 「向心/离心」依赖稳定对象集的选取，选取本身是主观建模行为 |
| 反馈层厚度（F1–F5 是否「尽收」） | 无法证明反馈集完备——未到来的现实反馈不可枚举 |
| 残余问题趋零 | 残余问题清单是登记制的：未登记≠不存在 |

### 3.3 判据草案结论

递归的实用语义是：**每轮以 §1 门禁保证闭环质量，以 §3.1 强判据判断「本轮是否较上轮更稳定」，以 §3.2 弱代理指标诚实标注不可判定部分**。当强判据连续 N 轮全绿且触发表静默，可宣布「当前扰动谱下达到动态相对稳定」——但这是可撤销的宣告：任何新层反馈（如【参考】F5 下游真实消费）到达即开启新一轮。

## 4. 结论（含出处）

1. **六阶段闭环成立且各阶段可设硬门禁**：原文主链五环节 + 实施后总体检视构成六阶段；每阶段的输入/输出/工件/门禁均可从【参考】§1–§5 找到实例化范式（出处：【原文】主链句；【参考】§0 主链定位、§1–§5 各阶段对应节）。
2. **关键术语全部有据可查，无需臆造**：1115 四步、六类方法、APX 裁决、向心关系、相位裕度、L1–L4 风险分级在【参考】§2–§4 均有实例化定义；唯一注明的是 APX 缩写字母含义仅由【参考】§4.1 用法隐含给出（出处：【参考】§2、§3、§4.1–4.3）。
3. **「动态相对稳定」可部分操作化**：单轮闭环、断点收敛、验证通过率、相位裕度监控四项强判据可直接检验；整体稳定达成、向心收敛、反馈完备性只能弱代理（出处：【原文】末句「持续逼近动态相对稳定」；【参考】§6 结论 4、§5.3 触发表）。
