# DSH 插件开发提案

## 背景

DeepSeek Harness（DSH）已具备完善的插件生态基础：社区插件市场 dsh-plugin-hub 收录 10000+ 精选插件并每日更新，可直接在「设置 → 插件中心」内浏览与安装；另有 dsh-plugin-market、DSH-Plugins-Marketplace 等市场入口，以及配套的发布流程与安全审核机制。分发渠道也较多元，既支持市场内安装，也可通过 npm（如 @nanmicoder/dsh-plugin-market）分发。详见 demo/findings.md。

## 建议

基于上述发现，建议开发一款定位清晰、切口小的 DSH 插件，而非重复造市场类轮子：

1. **选题**：优先填补现有 10000+ 插件未覆盖的细分场景（如本地工作流自动化、文档摘要、代码审查辅助），先在 dsh-plugin-hub 中检索确认无同质插件。
2. **架构**：遵循 DSH 插件规范，采用 Tools/界面（UI）类插件形态，保持只读优先，降低审核与安全风险。
3. **分发**：首发提交 dsh-plugin-hub，走其发布与审核流程；同步发布等价 npm 包，覆盖偏好命令行安装的用户。
4. **安全**：对齐 dsh-plugin-market 强调的安装前安全审核标准，声明最小权限、无网络外传，提升上架通过率与用户信任。

## 下一步

1. 在 dsh-plugin-hub 检索目标场景，确认选题空白并输出竞品简表（1 天）。
2. 阅读 DSH 开发者文档的插件发布流程与审核要求，搭建插件脚手架（2 天）。
3. 完成 MVP 功能与基础测试，内部试用收集反馈（1 周）。
4. 提交 dsh-plugin-hub 审核，同步发布 npm 包，并根据审核意见迭代。
