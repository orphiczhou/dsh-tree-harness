# 信息架构 / 页面结构清单（Sitemap）

> 文档编号：UX-02 | 隶属：02_UX_DESIGN | 依据：PRD §3（两道门）、§7.1–§7.6、§12.6（内部看板）
> 版本：v1.0 | 日期：2026-11-15 | 角色：UI/UX顾问（t28a-W3-ux）

---

## 1. 目的与范围

定义平台桌面应用的完整页面结构：**用户前台区**（零基础用户可见）与**内部研究区**（仅研究者可见，单列、互不混杂）。每个页面给出入口、核心元素与去向，供后续架构设计与前端Agent实现参照。

## 2. 信息架构总览

```
向导助手（桌面应用）
├── A. 用户前台区（零基础用户）
│   ├── P0 启动欢迎页
│   ├── P1 模式选择 · 两道门
│   ├── P2 会话工作区（聊天主界面）★用户全程主界面
│   │     ├─ P6 交付确认卡（内嵌卡片，非独立页）
│   │     └─ 侧边入口：预览 / 时间轴 / 设置
│   ├── P3 原型预览区（点选纠错）
│   ├── P4 时间轴页（自动备份·一键回滚）
│   └── P5 设置与隐私说明
└── B. 内部研究区（仅研究者账号可见，入口隐藏）
    ├── R1 效率看板
    ├── R2 Token效率图
    ├── R3 认知摩擦指数
    ├── R4 文档合规趋势
    └── R5 范式挖掘
```

**架构原则**（对齐 PRD §7.1「零门槛」）：用户常规旅程只经过 P0→P1→P2（含 P6），P3/P4 由 P2 侧边入口或对话内卡片跳入；**没有任何技术配置面板出现在前台区**。

## 4. 页面明细

### P0 启动欢迎页
- **定位**：第一次见面，30 秒内建立安全感。
- **核心区块**：向导问候语（§7.5 文案口吻）；一句隐私承诺「你的内容保存在你自己的电脑上」；唯一按钮「开始」。
- **离开动作**：点「开始」→ P1。

### P1 模式选择 · 两道门
- **定位**：PRD §3「必须明确选择其一（不可模糊进入）」。
- **核心区块**：两张门卡片（快消型：「快速做一个能用的」；长期迭代型：「长期慢慢打磨」）；每卡 3 条特征 + 选择按钮；底部「你帮我决定」入口（弹推荐说明后确认）。
- **规则**：不可跳过；选完显示确认条「好的，就按…来」→ P2；界面承诺「选错了以后都能改」（切换规则见 PRD §3.3）。

### P2 会话工作区（用户全程主界面）
- **定位**：唯一常驻界面；用户始终只面对一个「向导」（PRD §4.2，角色后台静默切换，UI 不暴露）。
- **核心区块**：
  1. 消息流：向导气泡（左侧，带阶段小徽章但不显示角色技术细节）／用户气泡（右侧）；
  2. 卡片单选题：每题附「你帮我决定」；
  3. 自由输入框：占位语「用你自己的话告诉我就行…」；
  4. 进度提示条：>5 秒操作出现，含 §7.5「等待中」文案位；
  5. 快照提示条：自动备份完成时轻提示（4 秒自退）；
  6. 侧边入口：「看看效果（预览）」「历史足迹（时间轴）」「设置」。
- **内嵌 P6**：交付确认卡。

### P3 原型预览区（点选纠错，PRD §7.3）
- **核心区块**：预览画布（原型以模拟数据呈现，可交互）；悬停虚线高亮可点元素；点选→标注气泡（快选 chip + 自由描述）；「想改的地方」清单（可单条撤销）；「让向导开始改」；修改前快照提示；修改后预览自动刷新 + §7.5「修改成功」文案。
- **离开动作**：「整体都还行，去确认」→ 回 P2 确认流程；「去历史足迹」→ P4。

### P4 时间轴页（自动备份与回滚，PRD §7.4）
- **核心区块**：一条线性时间轴（仅直线、无分叉视觉）；每项 = 时间戳 + 自然语言描述 + 徽章（当前版本／存档）；每项「回到这里」按钮（当前版本除外）→ 二次确认弹窗（弹窗含「现在这份也会存起来，不会丢」）→ 回滚过渡 → §7.5「回滚完成」提示；页首说明「快照由我自动管理，你不用记着点保存」。
- **规则**：不提供手动建快照入口；回到旧版后旧版之后的记录转为「存档」徽章，仅保留不作分叉。

### P5 设置与隐私说明
- **核心区块**：数据保存 30 天、可手动删除（§12.2）；编程在你电脑本地进行（§1.3）；研究数据脱敏、不含业务内容（§12.2）；快消↔长期模式切换说明（§3.3）。全部生活化措辞，无技术开关。

### P6 交付确认卡（内嵌 P2）
- 快消型：测试用例全部通过（裁判判定）→ 卡片「做好了，来试试！」+ 试用入口 + 「有不满意的地方，直接点预览里的东西告诉我」。
- 长期迭代型：每 Sprint 交付卡 + 版本号（生活化：「第 1 期改好的东西」）。

## 5. 内部研究区（单列，不对用户暴露）

| 编号 | 看板 | 内容（PRD §12.6） | 可见性 |
|------|------|------------------|--------|
| R1 | 效率看板 | MVP 触达时间、成功闭环率、项目类型对比 | 仅研究者账号 |
| R2 | Token效率图 | 各阶段 Token 消耗占比 | 仅研究者账号 |
| R3 | 认知摩擦指数 | 用户意图修正次数 / 总交互轮数 | 仅研究者账号 |
| R4 | 文档合规趋势 | 裁判Agent通过率项目间对比 | 仅研究者账号 |
| R5 | 范式挖掘 | 「高效用户」对话模式聚类 | 仅研究者账号 |

**隔离规则**：前台区任何页面不出现研究区入口；研究区不展示未脱敏业务内容；两区视觉体系分离（研究区可用信息密度高的表格语言，不受 §7 文案规范约束，但仍不得含源码级术语向用户回流）。

## 6. 全局元素（跨页面）

| 元素 | 出现页面 | 说明 |
|------|---------|------|
| 顶栏 | 全部前台页 | 应用名「向导助手」+ 当前步骤示意（选门→聊天→看效果） |
| 快照提示条 | P2/P3 | 自动备份完成时轻提示「已自动备份：〈人话描述〉」，4 秒自退，可点去 P4 |
| 进度提示条 | P2/P3 | >5s 出现；文案位遵循 interaction-spec §5 阈值 |
| 本地安心位 | P0/P2 底部 | 「你的内容保存在你自己的电脑上。」 |
| 「你帮我决定」 | P1/P2 全部选择题 | PRD §7.6：每个选择问题必须提供 |
| 回滚入口 | P4 常驻；P2 消息流异常时插入快捷入口 | 失败场景一键回上一正常版本 |

## 7. 页面流转图

```
P0 启动欢迎 ──开始──▶ P1 两道门 ──选卡/你帮我决定──▶ P2 会话工作区
                                        │                     │
                        (选错承诺:设置可切换)│                     ├──卡片里「打开原型看看」──▶ P3 预览·点选纠错
                                             │                     │        │点选→气泡→开始改→自动刷新
                                             ▼                     │        │「整体都还行」→回P2确认
                                          P2(快消型/长期型同界面)  ├──「历史足迹」──▶ P4 时间轴·回滚
                                                                   │        │一键回滚(二次确认)→回P2继续
                                              测试全通过(P6交付卡)◀─┤        └──侧边──▶ P5 设置与隐私
                                                                   ▼
                                                          P2 循环反馈/升级长期型
```

## 8. 可见性与权限规则

| 对象 | 能看到 | 看不到（被隐藏） |
|------|--------|----------------|
| 零基础用户 | P0–P6 全部、生活化文案、自动备份 | 源码、PlantUML、GWT 文件、Agent 角色切换过程、技术配置面板、研究区 |
| 研究者 | 前台区全部 + R1–R5（独立账号） | 他人未脱敏业务内容（§12.2） |
| 编程Agent（后台） | 全部文档体系 | 不直接面向用户界面 |
