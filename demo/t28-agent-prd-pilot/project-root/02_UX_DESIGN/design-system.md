# 设计系统（Design System）

> 文档编号：UX-04 | 隶属：02_UX_DESIGN | 依据：PRD §2.4 恐惧点、§7.1 设计原则、§7.5/§7.6 交互要点
> 版本：v1.0 | 日期：2026-11-15 | 角色：UI/UX顾问（t28a-W3-ux）
> 适用：wireframes/ 全部原型 + 前端Agent UI 实现（原型 HTML 即 UI 模板，PRD §7.2）

---

## 1. 设计理念：安全感 + 零门槛

| PRD 恐惧点（§2.4） | 设计转译规则 |
|-------------------|-------------|
| 怕看到代码 | 全界面无代码元素；预览优先（一切确认都发生在「看得见的样子」上） |
| 怕搞坏东西 | 每个大动作前自动备份提示；危险动作二次确认；随时可回旧版本 |
| 怕隐私泄露 | 「本地保存」安心位常驻两处（P0/P2）；设置页给脱敏说明 |
| 怕AI做的不对 | 原型确认为主流程节点；成功提示永远附「不满意随时告诉我」 |
| 怕操作太复杂 | **卡片选择优先于输入、单选优先于填空**；每题配「你帮我决定」 |
| 怕等待焦虑 | 进度提示条 + 安抚文案位（五条心理文案中的「等待中」主位） |

**两条铁律**：① 界面文案不得出现任何技术术语（见 §7 禁用词表）；② 任何失败都翻译为「已回到正常版本，内容没有丢失」句式。

## 2. 色彩

### 2.1 色板

| 令牌 | 色值 | 用途 |
|------|------|------|
| `--c-primary` | `#2E9E6B` 安心绿 | 主按钮、选中态、成功语义、进行中 |
| `--c-primary-deep` | `#1F7A52` | 主按钮按下/悬停深一档 |
| `--c-primary-soft` | `#E9F6EF` 浅绿底 | 选中卡片底色、成功提示底 |
| `--c-bg` | `#F7F5F0` 暖米白 | 全局背景（纸感、不刺眼） |
| `--c-card` | `#FFFFFF` | 卡片、气泡、弹层 |
| `--c-text` | `#2B2A26` 墨黑（暖） | 主文字 |
| `--c-text-sub` | `#6E6A60` | 次要文字、说明 |
| `--c-text-weak` | `#9A958A` | 占位符、时间戳 |
| `--c-line` | `#E5E1D8` | 分隔线、卡片描边 |
| `--c-warn` | `#E8A13C` 暖橙 | 等待较久、温和提醒（禁用于报错恐吓） |
| `--c-warn-soft` | `#FBF3E4` | 提醒底色 |
| `--c-error` | `#D96459` 温和珊瑚红 | **仅**失败/回滚场景小面积点缀（徽章、细线），禁大色块 |
| `--c-rollback` | `#4A7EBB` 信任蓝 | 回滚、时间轴、历史元素 |
| `--c-snapshot` | `#8071A8` 藕紫 | 快照/自动备份徽章、提示条左侧竖线 |

### 2.2 用色规则

- 正文对比度 ≥ 4.5:1；按钮文字（白字于主绿）对比度 ≥ 4.5:1。
- **红色封顶**：任何屏内珊瑚红面积 ≤ 屏 5%，只允许细线、小徽章、图标描边；禁止红色全屏弹窗。
- 语义色不得复用装饰：绿色只与「成功/进行/可继续」绑定，蓝色只与「历史/回滚」绑定。
- 原型（预览区）内容色不受本表约束，但预览外框、引导条使用本表色。

## 3. 字体

| 项 | 规范 |
|----|------|
| 字族 | `"Segoe UI", "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB", sans-serif`（系统栈，零加载） |
| 正文 | **17px / 行高 1.7**（刻意大于常规 14–16px：零基础用户多为大字阅读偏好） |
| 大标题（P0/P1 页标题） | 26px / 粗 700 / 行高 1.4 |
| 页标题 | 21px / 600 |
| 卡片标题 | 19px / 600 |
| 消息气泡 | 17px / 1.7 |
| 按钮 | 17px / 600 |
| 辅助说明/时间戳 | 14px / 1.5（**全系统最小字号，不得再小**） |
| 数字 | 与中文同族，不做等宽切换（保持柔和） |
| 加粗使用 | 仅用于承诺句关键词（「不会丢」「随时告诉我」），每屏 ≤2 处 |

## 4. 间距 / 圆角 / 阴影

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--sp-1` | 4px | 图标与文字微间距 |
| `--sp-2` | 8px | 元素内紧凑间距 |
| `--sp-3` | 12px | 组件内边距（按钮、输入框） |
| `--sp-4` | 16px | 卡片内边距、列表项间距 |
| `--sp-5` | 24px | 卡片间距、区块间距 |
| `--sp-6` | 32px | 页面级留白 |
| `--r-card` | 16px | 卡片 |
| `--r-btn` | 12px | 按钮 |
| `--r-input` | 12px | 输入框 |
| `--r-bubble` | 14px（对话侧收 4px） | 气泡 |
| `--r-chip` | 999px | 徽章、快选 chip |
| `--shadow-card` | `0 2px 8px rgba(43,42,38,.06)` | 卡片浮起 |
| `--shadow-pop` | `0 8px 24px rgba(43,42,38,.12)` | 气泡、弹层 |

8pt 网格：所有间距取 4 的倍数；卡片最小宽度 ≥ 280px（单列布局下 100%）。

## 5. 组件规范

> 状态缩写：D=默认 H=悬停 P=按下 S=选中 Dis=禁用

### C1 主按钮（决定性动作）
- 结构：实心安心绿底 + 白字；内边距 12×20；圆角 12。
- D→H 变深 8%；P 缩放 0.98；Dis 灰 `#C9C5BC` + 文字 `#8A867C`。
- 文案必须动词+承诺：「选这个，马上开始」「让向导开始改」。

### C2 次按钮（并列动作）
- 白底 + 1px `--c-line` 描边 + 墨字；H 底变 `#F2F0EA`。

### C3 幽灵按钮（退出/放弃类：「算了，不改了」「再想想」）
- 无底无框，灰字 `--c-text-sub`；H 加下划线。放弃类必须放右侧弱化位。

### C4 「你帮我决定」按钮（特权组件）
- 形态：浅绿底 `--c-primary-soft` + 深绿字 + 「✨」前缀；出现在**每张**选择卡下方与门页底部。
- H：底变 `#DCF0E6`。这是 PRD §7.6 的强制组件，任何选择题缺它 = 实现缺陷。

### C5 卡片选择卡（单选）
- 结构：白卡（描边 `--c-line`、圆角 16、阴影 card）+ 标题 19px + 说明 17px + 特征列表（每条前「·」）+ 底部选择按钮；标题右上可挂术语小徽章（如「快消型」）。
- S：描边变 2px 安心绿、底变浅绿、右上角出现绿色对勾圆徽（弹性动效见 interaction-spec §3）。
- 单选题卡片高度一致；每屏 ≤ 4 张选项卡；「你帮我决定」以 C4 常驻题尾。

### C6 对话气泡
- 向导：左对齐，白底，头像位「🧭」，可挂阶段小徽章（如「画好了」）；用户：右对齐，浅绿底。
- 成功/失败/回滚等心理文案气泡在白底上**首句前加图标**：成功 ✅、失败 🛟、回滚 ⏮（见 interaction-spec §4）。

### C7 输入框
- 白底、描边 `--c-line`、圆角 12、内边距 12；占位语生活化（「用你自己的话告诉我就行…」）。
- 聚焦：描边变安心绿 + 外发光 `0 0 0 3px rgba(46,158,107,.15)`。
- 标注气泡内的多行描述框同规格，高度 2 行起自适应。

### C8 进度提示条（含安抚文案位）
- 结构：`[呼吸圆点] [主文案 ≥17px]` + 第二行阶段小字 14px + 进度轨道（高 12px、圆角 6、底 `#EDEAE2`、填充安心绿、无百分比数字——零基础用户看百分比更焦虑）。
- 主文案位**绑定 §7.5 文案**（等待中/操作超时），不得填技术词（见 interaction-spec §4/§5）。
- 完成：填充满格 → 打勾动画 → 文案按场景切换（修改成功/回滚完成）。

### C9 快照提示条（轻提示/toast）
- 结构：白卡左缘 3px 藕紫竖线 + 「📸 已自动备份：〈一句人话〉」+ 可点「看看足迹」；右下滑入，4s 自退（动效见 interaction-spec §3）。
- 快照称呼规则：主称呼「自动备份」，首次出现括注（快照）。

### C10 快照时间轴项
- 结构：左侧蓝/紫时间点 + 右侧白卡：第一行「今天 15:24」14px 灰 + 第二行人话描述 17px 墨；右上徽章：`当前版本`（绿实心）/`存档`（灰描边）/`修改前备份`（紫描边）。
- 卡右侧「回到这里」次按钮（当前版本项无此按钮，改挂「你现在在这里」灰字）。
- 时间格式：今天/昨天 + HH:MM，禁止日期技术格式（不用 2026-11-15T15:24:33Z）。

### C11 标注气泡（点选纠错）
- 结构：指向被点元素的白卡（阴影 pop、圆角 14）+ 标题「你想把这里改成什么样？」+ 4 个快选 chip（换颜色/改文字/换个位置/说点别的）+ 描述框 + 按钮排「先记下来」（主）/「算了，不改了」（幽灵）。
- 出现动效 200ms 上浮；点空白处 = 收起不记录。

### C12 修改意图卡（清单项）
- 结构：浅黄便签感 `#FBF6E8` 底 + 一句话：「我点了【投票按钮】，想让它变成：更醒目一点。」+ 右上「不改了」幽灵小按钮。
- 未执行态左侧灰点；执行中变呼吸绿点；已执行变对勾。

### C13 确认弹窗（回滚等不可逆动作）
- 结构：居中白卡（宽 ≤ 480px）+ 标题 21px + 承诺正文（必须含「现在这份也会存起来，不会丢」句式）+ 按钮排「对，回到那里」（主）/「再想想」（幽灵）。
- 遮罩 `rgba(43,42,38,.4)`；Esc/点遮罩 = 关闭（=「再想想」）。

### C14 引导提示（首次可见性）
- 预览区顶条：浅蓝底 `#EAF1F9` + 「👆 看哪里不顺眼？直接点它试试」；用户完成第一次点选后自动收起不再出现。

### C15 徽章
- `当前版本`：绿实底白字；`存档`：灰描边灰字；`快消型/长期迭代型`：米底 `#F2EFE8` 灰字小徽章；`修改前备份`：紫描边。

### C16 空状态
- 场景：时间轴为空（新项目）、清单为空。结构：居中插画位 emoji（🗓️/📝）+ 一句话 + 幽灵按钮。文案示例：「还没有足迹。等我们开始做点东西，这里就会有记录。」

### 5.17 组件状态总表

| 组件 | D | H | P | S | Dis |
|------|---|---|---|---|-----|
| 主按钮 | 绿底白字 | 深 8% | 缩 0.98 | — | 灰底禁文字 |
| 选择卡 | 白底描边 | 描边加深、微上浮 2px | — | 绿描边浅绿底对勾 | 半透明不可点 |
| 输入框 | 灰描边 | 描边加深 | — | 聚焦绿描边发光 | 半透明 |
| 时间轴项「回到这里」 | 次按钮 | 同 C2 | — | — | — |
| 快选 chip | 白底描边 | 浅绿底 | — | 选中实心绿 | — |

## 6. 图标

仅用系统 emoji（零资源依赖）：🧭 向导、📸 备份、✅ 成功、🛟 失败安抚、⏮ 回滚、👆 点选引导、✨ 你帮我决定、🗓️ 时间轴、⚙️ 设置、🔒 隐私。**禁止**引入需要网络加载的图标库（原型单文件自包含）。

## 7. 文案风格规范（向导的「声音」）

| 规则 | 正例 | 反例（禁） |
|------|------|-----------|
| 自称「我」，称用户「你」 | 「我帮你回到上一个正常版本」 | 「系统已执行回滚操作」 |
| 动作有承诺 | 「不满意随时告诉我」 | 「请等待处理完成」 |
| 生活化比喻 | 「像游戏存档一样」 | 「基于快照链的版本管理」 |
| 失败=安抚+出路 | 「我们换个思路试试？」 | 「操作失败，错误码 E-502」 |
| 短句，一句一事 | 「改好了，你看看效果？」 | 「本次变更已成功应用至预览环境」 |

**禁用词表（前台区界面一律不得出现）**：代码、报错、异常、构建、编译、部署、数据库、API、接口、前后端、源码、分支、合并、刷新缓存、日志、Token、模型、Agent、快照链、版本号（用「第 N 期」）、PRD（用「一份小计划」）、GWT（用「验收场景」内部词也不得露出）。
**五条心理防御文案（PRD §7.5）为最高优先级基准**，任何界面冲突以原文为准（逐字见 interaction-spec §4）。

## 8. 可访问性与容错

- 点按目标 ≥ 44×44px（含「回到这里」「不改了」等小按钮的外扩热区）。
- 全局最小字号 14px；正文 17px；不使用纯色块区分状态（加图标/文字冗余）。
- 弹窗支持 Esc 关闭；确认弹窗焦点默认落「安全选项」（再想想）。
- 等待界面允许随时切走（时间轴/设置），回来进度不丢。
- 削弱动效偏好（`prefers-reduced-motion`）时，动效全部降级为直接切换（interaction-spec §2）。
