# DeepSeek Harness 插件（Plugin/Market）检索要点

1. **dsh-plugin-hub 社区插件市场**：DeepSeek Harness 社区提供内置插件市场（dsh-plugin），号称收录 10000+ 人工精选社区插件，每日更新、免费，集成在 Harness「设置 → 插件中心」，无需离开应用即可浏览、搜索与安装。来源：https://github.com/dshplugin/dsh-plugin-hub

2. **dsh-plugin-market 插件市场项目**：GitHub 上有独立维护的 Plugin Market for DeepSeek Harness，定位是在 DSH 内部发现（discover）、审查（vet）并安装 DSH 插件，强调安装前的安全审核流程。来源：https://github.com/duxingxiake3/dsh-plugin-market

3. **插件发布流程与审核**：开发者文档介绍了如何把 DSH plugin 提交到 DSH Plugin Hub，包括 DeepSeek Harness 插件的发布流程与审核机制，是插件作者上架的参考指南。来源：https://developer.aliyun.com/article/1767678

4. **DSH-Plugins-Marketplace 工具类插件**：dshbase 插件库收录了名为 DSH-Plugins-Marketplace 的 Tools 类 DSH 插件，可用作插件市场入口，并给出「已安装判定」等使用说明。来源：https://dshbase.com/plugins/DSH-Plugins-Marketplace/

5. **dsh-market 界面插件与 npm 分发**：dsh-market 是一个 UI（界面）类插件，同时存在 dshmarket 等 npm 包，说明 DSH 插件既可通过插件市场，也可经 npm（如 @nanmicoder/dsh-plugin-market）分发安装。来源：https://www.dshbase.com/zh/plugins/dsh-market/ 与 https://www.npmjs.com/package/@nanmicoder/dsh-plugin-market
