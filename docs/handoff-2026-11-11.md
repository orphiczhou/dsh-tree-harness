## 4. 测试与验活命令

### 跑测试

```powershell
# 执行层：67/67
cd packages\dsh-tree-engine
node --test tests/*.test.js

# 治理层：13/13
cd ..\dsh-meta-loop
node --test tests/*.test.js

# 会话树单包（3 份 cjs）
cd ..\dsh-session-tree
node test/render.test.cjs
node test/style-guard.cjs
node test/provider-conformance.cjs [asar 解包目录]   # 默认 %TEMP%\dsh-asar-inspect\out
```

⚠️ **不要用目录形参 `node --test tests`**：Node 24 会把 `tests` 当文件路径，报 `test at tests:1:1` 假失败；要 TAP 计数加 `--test-reporter=tap` 且必须放在位置参数**之前**。
⚠️ `provider-conformance.cjs` 需要一份 DSH `app.asar` 解包树（含 `dsh/node_modules/@deepseek-ai/dsh-tools/...`）；缺目录时 ENOENT，属环境依赖，不是代码失败。DSH `0.2.2-rc.1` 把 schema 引擎拆到 shared chunk，测试的 region 提取启发式仍是旧版内联布局 → 需 rc.2 兼容解包 fixture 才能得到 29/29 判定（细节见 [merge-session-tree-2026-11-11.md](merge-session-tree-2026-11-11.md) §5；测试布局适配留待下次 bump，D6 本轮不改包内容）。

1. **meta-loop 未装配**：不在 profile bundles，`/metaloop/` 面板与胶囊入口当前不可用；源码/测试/面板齐备，装载即加载。

7. **flash 审计积压**：33 条问题（[flaudit-report.md](flaudit-report.md)），严重级 3 条已抽查属实（`.lock` 文件锁未实现 / nudge 绕 `assertTransition` / `leafAdd` 字段透传无白名单）；采纳前逐条复核。

10. **会话树 `provider-conformance` 测试存在环境 + 布局双依赖**（见 §4）：需 asar 解包 fixture，且 DSH 0.2.2-rc.1 的 shared chunk 布局与测试的旧版启发式不一致，需 rc.2 兼容 fixture 才能 29/29；测试布局适配留待下次 bump（[merge 记录](merge-session-tree-2026-11-11.md) §5）。
