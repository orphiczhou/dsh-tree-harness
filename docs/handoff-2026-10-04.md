## 4. 血泪换来的 DSH API 事实（勿再踩）

1. `subagents.startContinuable(spec)`：
   - `spec.provider` = **'spawn'|'fork'（会话生成机制名，不是 LLM 供应商！）**
   - `spec.signal` = AbortSignal **必填**（服务调 throwIfAborted）
   - `spec.request.parent` = **活 Agent 对象必填**（`ctx.agents.get(parent.id)===parent` 强校验；来源=工具调用 `exec.agent`）
   - `spec.request.prompt` = ContentBlock[]；`spec.request.agentOptions = {provider, model, reasoningEffort}` 才是模型路由
   - 返回 `{childId, messageId}`（**childId** 不是 sessionId）
2. `subagents.interrupt(sessionId, {kind:'parent', parentSessionId})`——持久父地址即可，无需活 Agent
3. `exec.agent.session` = 调用者会话；`exec.agent` = 活 Agent
4. **`ctx.timer` 在插件 apply 上下文访问即抛**（"cannot get property without inject"）——用 try/catch 兜（现状 sweep 落在裸 setInterval）
5. cordis inspect `Tool.listTools`/`Service.listService` 拒绝任何 object 入参（通道 bug）——API 权威走 asar-tool 直读实现源
6. **PowerShell `Set-Content` 会以系统编码毁 UTF-8 中文文件**——文件一律用 write/edit 工具
7. Loader 按包名缓存宿主模块（换内容需新代际）；pnpm 11.7.0 锁文件校验忽略 `minimumReleaseAgeExclude`（24h 冷静期 bug，见 bug-report 文档）——profile 里装新插件可能再被拦，等 24h 或 `--config.minimum-release-age=0`
