## 4. 测试与验活命令

### 跑测试

```powershell
# 执行层：67/67
cd packages\dsh-tree-engine
node --test tests/*.test.js

# 会话树单包（handoff + render + style + skills）
cd ..\dsh-session-tree
node test/render.test.cjs
node test/style-guard.cjs
node test/provider-conformance.cjs [asar 解包目录]   # 默认 %TEMP%\dsh-asar-inspect\out
```

⚠️ **不要用目录形参 `node --test tests`**：Node 24 会把 `tests` 当文件路径，报 `test at tests:1:1` 假失败；要 TAP 计数加 `--test-reporter=tap` 且必须放在位置参数**之前**。
⚠️ `provider-conformance.cjs` 需要一份 DSH `app.asar` 解包树（含 `dsh/node_modules/@deepseek-ai/dsh-tools/...`）；缺目录时 ENOENT，属环境依赖，不是代码失败。DSH `0.2.2-rc.1` 把 schema 引擎拆到 shared chunk，测试的 region 提取启发式仍是旧版内联布局 → 需 rc.2 兼容解包 fixture 才能得到 29/29 判定（细节见 [merge-session-tree-2026-11-11.md](../architecture/merge-session-tree-2026-11-11.md) §5；测试布局适配留待下次 bump，D6 本轮不改包内容）。

## 7. 已知边界（诚实清单）

1. **tree-engine sweep**：宿主 timer 服务可用时用其 interval；不可用时 `systemClock()` 进程内 60s 兜底（`sweepMode` 恒为 `timer`）。不要假设「必须显式 harvest」；`tree_status harvest` 只是立即触发一轮。
2. **RC2 兼容层未补单测**：新增的 `startContinuable` / `startActivation` 双形探测分支未被 67 项测试覆盖，补测列为后续（R3）。
3. **npm 冻结（D3）**：三个候选包名 npm 404；只走 Git / `link:` 安装。
4. **artifact 验证对象错位**：`**/*.md` 按字典序取首个匹配，可能命中 `node_modules` 里的 md；应支持 leaf 产物路径或排除 `node_modules`（未修）。
5. **leaf.status 与 runtime 终态脱节**：runtime `succeeded` 后 `status` 可能停留 `pending_brief` / `active`（观察者易误读）。
6. **flash 审计积压**：33 条问题（[flaudit-report.md](../archive/flaudit-report.md)），严重级 3 条已抽查属实（`.lock` 文件锁未实现 / nudge 绕 `assertTransition` / `leafAdd` 字段透传无白名单）；采纳前逐条复核。
7. **未接项**：`observeSession` 事件面（宿主形状未冻结）、llm-judge 宿主 judge 端口、源 `tests/` 五个 `.test.cjs` 移植、sweep 用裸 `setInterval`（未托管 disposal）、完整性签名（D-v4）/ `E_CALLER_REQUIRED`（D-v2）。
8. **`tree_maintain gc` 未实现**：`tree-engine-data\` 下历史 smoke/e2e 测试树只能手工清理。
9. **会话树 `provider-conformance` 测试存在环境 + 布局双依赖**（见 §4）：需 asar 解包 fixture，且 DSH 0.2.2-rc.1 的 shared chunk 布局与测试的旧版启发式不一致，需 rc.2 兼容 fixture 才能 29/29；测试布局适配留待下次 bump（[merge 记录](../architecture/merge-session-tree-2026-11-11.md) §5）。
10. 更早的踩坑记录（客户端模块契约 / Inspect Provider 写法 / 胶囊定位 / 工程纪律等）仍以 [handoff-2026-10-14.md](../archive/handoff-2026-10-14.md) §4–§5 为准。
