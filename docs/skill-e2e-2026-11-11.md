## 1. 判定协议（旁证口径，不依赖被测实现）

### 1.1 「skill 被看到」

- 数据源：会话日志 `%USERPROFILE%\.dsh\sessions\<workspace-encoded>\<sessionId>\session.v4.jsonl.zstd`（多 zstd frame 拼接；扫魔数 `28 B5 2F FD` 逐帧 `zstdDecompressSync`，按 `type+seq` 去重）。
- 判定：会话 `user/message` 内的 `<system-reminder>…<available_skills>…</available_skills>…</system-reminder>` 块里出现目标 skill 名。
- **重要事实**：skill provider 热加载后，DSH 会在**后续 user/message** 追加刷新后的 catalog。因此本协议区分两个快照：
  - `atCreation` = 会话创建时首个 catalog（子会话 spawn 那一刻可见的 skill 集）；
  - `latest` = 最后一次注入的 catalog（当前活体加载结果）。
- 工具：`scripts/skill-e2e/collect-skills.mjs`（默认 `--expect-at latest`，同时输出 `atCreation` 与 `evolution`）。

### 1.2 「skill 被使用」

- 强证据：会话调用 `skill {name:"tree-commander"|"tree-worker"|"session-handoff"}` 的 `tool/call`，以及其后确实按 skill 命令序列调用 `tree_*` / `session_handoff`；
- 弱证据：未加载 skill 正文但工具调用序列与 skill 命令序列同构（记「按 skill 语义执行，未显式加载」）。
- 注：工具名/参数在工具列表里本就可见，因此「看到了 skill」与「真的用了 skill」必须分开取证。

### 1.3 「三层分解」

从会话日志（含子会话日志）汇总：

- `tree_plan {action:"create", tree_id, root_brief, root_dod}` → 建树（root leaf 由引擎自动创建）；
- `tree_node {action:"add", leaf:{leaf_id, parent, role, taskType, dependencies, added_by}}` → 节点层级/角色；
- `tree_dispatch {action:"start", leaf_id}` → 派发独立会话（子会话首轮 user/message 含 `你是树节点 <tree>/<leaf> 的执行者`，用于建立 会话↔leaf 归属）；
- `tree_report {action:"event"|"context"}` → 各层真实工作（`brief_echo`/`progress`/`done`）与水位自报；
- `tree_verify {action:"run"}` → 逐点验收裁决（`tree_verify: PASS/FAIL`）；
- 判定：树深度 ≥2（3 层）、存在 commander+worker、≥2 个不同会话执行过 `tree_dispatch`（每层能继续分层）、执行层有 `done` 上报、有 verify 记录。
- 工具：`scripts/skill-e2e/summarize-run.mjs`（同时输出完整工具调用序列、子会话发现、启发式 checks）。

### 1.4 「50% 自主交接」

- 数据源：`session_handoff` 的 `tool/call` + `tool/result` 文本（`session_handoff status: context=…% (threshold 50%) … successor=…` / `session_handoff: wrote … successor <id> kind=… preset=… workspace=… inherited=…`）；
- 阈值语义：`status.context_pct` 与默认阈值 50% 比较；**子会话若上下文远低于 50%，允许 `force:true` 模拟阈值场景**，报告须注明「模拟」；
- successor 继承断言：`scripts/e2e/verify-handoff.mjs --source <层会话> --successor <id> --expect-kind sibling|root`（cwd/工作区归属/permission 三元组/agentPreset/模型配置/工具数/交接提示/首轮读 HANDOFF）。
